## Description

支撑所有节点运行的基础设施层：

- **DVB_Config**: 从 `config.json` 读取 UI 配置（图标、类别名称），支持与默认配置自动合并
- **StateFile/StateStore**: `DRV_StateFile` 将键值数据持久化为 JSON 文件（存储在 ComfyUI temp 目录），`DRV_StateStore` 提供命名空间隔离的存取接口
- **Memory**: `gc_comfyui()` 清理 ComfyUI 模型缓存 + CUDA 内存，在批量处理前后调用
- **Error**: `on_node_error()` 格式化错误消息（"[节点名]:错误"）并抛出异常，`raise_error()` 通用异常
