## Description

批量文件处理系统，按目录迭代处理所有匹配文件：

1. **DVB_ForEachFilename** — 首个节点，扫描 glob 模式匹配的文件，使用 `ForEachState` JSON 文件记录进度。返回下一个未处理文件的路径。使用 Unique ID 区分不同迭代器
2. **DVB_ForEachCheckpoint** — OUTPUT_NODE，标记文件处理完成并推进迭代器

**ForEachState 机制**:
- JSON 文件作为状态存储（`foreach_{id}.json`）
- 键为文件路径，值为处理状态（bool）
- `pop()` 返回第一个未处理文件，`mark_done()` 标记完成

**共享工具** (TC-014):
- `list_files_in_directory()` — 支持 batch_0001 子目录结构和字母/数字索引
- `pick_random_by_weight()` — 加权随机选择
