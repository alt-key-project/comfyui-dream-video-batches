## Description

加权提示词构建系统，专为 AnimateDiff 等视频生成工作流设计：

- **PartialPrompt** — 核心模型，字典存储 `{text: weight}` 对，weight > 0 为正提示词，< 0 为负提示词
- **DreamWeightedPromptBuilder** — 构建权重化 Prompt 片段
- **DreamPromptFinalizer** — 输出格式化的正/负提示词字符串
- **RandomPromptScheduleGenerator** — 为每帧生成随机采样的提示词调度表，支持 seed、interval、调整模式（raw/by_abs_max/by_abs_sum）和 clamp

输出格式: `(text:weight)` 元组，所有节点分类在 `conditioning` 下。
