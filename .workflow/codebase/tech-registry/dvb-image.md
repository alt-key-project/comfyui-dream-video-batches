## Description

统一图像处理类，封装了 PIL Image 和 PyTorch Tensor 的双向转换。支持：
- **格式转换**: `tensor_image` / `pil_image` / `numpy_array` 属性，延迟转换
- **裁剪**: `crop(x1, y1, x2, y2)`
- **旋转**: `rotate(degrees_cw)`
- **缩放**: `resize(width, height)`
- **混合**: `blend(other, weight_self, weight_other)`
- **亮度/对比度**: `change_brightness(factor)`, `change_contrast(factor)`
- **模糊**: `blur(amount)`
- **色彩调整**: `adjust_colors(red, green, blue)`
- **色域转换**: `convert(mode)`

静态方法：
- `join_to_tensor_data(images)` — 将 DVB_Image 列表转为 tensor
- `images_from_tensor_data(tensor)` — 将 tensor 转为 DVB_Image 列表
- `from_file(file_path)` — 从文件路径加载
- `empty(width, height, mode)` — 创建空白图像
