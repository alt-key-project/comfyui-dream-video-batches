## Description

相机动画节点集，通过裁剪（crop）实现相机运动效果。所有相机节点输出帧尺寸小于输入，以提供运动空间。

**运动函数模式**:
- 线性模式: `f(t)` 直接映射时间因子
- 正弦模式: `sin(t * 2π / period + phase) * 0.5 + 0.5` 产生振荡

**BatchCameraMotion** 是核心执行器，接收 motion_function（位置计算）和 frame_function（逐帧变换），使用 `DVB_ImageBatchProcessor` 批量处理。

依赖: `Vector2d` / `Quad2d` 做几何计算（平移方向向量、裁剪区域交点）
